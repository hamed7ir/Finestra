The bundled RDP engine (wfreerdp.exe, the x64 and ARM32 builds) is built from
FreeRDP release 3.28.0 WITH MODIFICATIONS. There are FOUR modifications, listed
below. The complete modified source is published as the branch

    finestra-arm32-rt-3.28   at   https://github.com/hamed7ir/FreeRDP

cut from upstream tag 3.28.0, so every modification below is one commit on that
branch and reads directly as a diff against unmodified 3.28.0.

  1. WinPR internal-SSPI package-index dispatch fix
     Files: winpr/libwinpr/sspi/sspi.h, winpr/libwinpr/sspi/sspi_winpr.c,
            winpr/libwinpr/sspi/NTLM/ntlm.c, winpr/libwinpr/sspi/Negotiate/negotiate.c
     The internal SSPI stored the security-package name in the context handle's
     upper pointer with MIXED character width (WCHAR vs char), so UNICODE builds
     with WITH_NATIVE_SSPI=OFF failed NLA with SEC_E_SECPKG_NOT_FOUND. The fix
     replaces the name-in-pointer scheme with a width-agnostic package INDEX.
     Commit: 8eca47218
     Also submitted upstream as FreeRDP pull request #13136.

  2. Windows client: embedding + live stats/control pipe
     Files: client/Windows/wf_client.c, client/Windows/wf_event.c,
            client/Windows/wf_event.h
     Adds /parent-window child-embedding behavior fixes and a per-PID local
     named pipe (\\.\pipe\finestrardp.<pid>) that reports live RTT/bandwidth
     from FreeRDP's autodetect and accepts PAUSE/RESUME (suppress-output).
     Commit: 0ecc589d1

  3. Build configuration
     File: CMakeLists.txt
     Adds a WIN81 target case (WINVER/_WIN32_WINNT=0x0603) for the Windows
     RT 8.1 floor and related build-configuration adjustments.
     Commit: 9a31cc2a5

  4. Windows client: DPI-aware cursor scaling
     File: client/Windows/wf_graphics.c
     The RDP session's hardware cursor was built directly from the server's
     raw protocol pixel size with no DPI adjustment, rendering it visibly
     undersized on any display above 100% Windows scaling. Adds a DPI query
     (GetDpiForWindow, resolved dynamically via GetProcAddress so it never
     appears as a static import — required for the Windows RT 8.1 loader,
     which lacks that Windows-10-only export; falls back to the universal
     GetDeviceCaps(LOGPIXELSX) query where GetDpiForWindow is unavailable)
     and rescales the built cursor icon to match via CopyImage.
     Commit: 8f0675c2e

The ARM32 / Windows RT cross-build toolchain used to produce the ARM engine is
published on the same branch under finestra-rt/, with its own NOTICE.txt and
licence files. It adds no changes to FreeRDP or WinPR source.
